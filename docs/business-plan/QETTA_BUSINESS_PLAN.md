# Qetta 사업계획서

> **in·ev·it·able**
> *Data Flows. Evidence Follows.*

---

## Executive Summary

**Qetta**는 중소 제조업의 디지털 전환을 **필연적(inevitable)**으로 만드는 스마트공장 증빙 자동화 SaaS입니다.

| 항목 | 내용 |
|------|------|
| **회사명** | Qetta (켓타) |
| **슬로건** | in·ev·it·able |
| **태그라인** | Data Flows. Evidence Follows. |
| **핵심 제품** | OTT칩 + AI 예지보전 + Gov ZIP |
| **목표 시장** | 스마트공장 10,432개 Pool SI + 수요기업 |
| **핵심 가치** | MES 대비 99% 비용 절감, 10분 설치 |

---

## 1. 문제 정의 (Problem)

### 1.1 제조업 현실

```
"스마트공장? 우리 같은 작은 공장은 꿈도 못 꿔요."
                                    - 50인 미만 제조업 대표
```

**현재 상황:**
- 스마트공장 도입률: 대기업 95% vs 중소기업 12%
- MES 도입 비용: 평균 3억원 (중소기업 연매출의 10-30%)
- 도입 기간: 6-12개월
- 정부 지원금 수령 후 **증빙 서류 준비에 평균 2주** 소요

### 1.2 핵심 Pain Points

| Pain Point | 현재 | Qetta 솔루션 |
|------------|------|-------------|
| **높은 비용** | MES 3억원 | OTT칩 50만원 |
| **긴 도입기간** | 6-12개월 | 10분 설치 |
| **복잡한 증빙** | 수작업 2주 | 자동 생성 |
| **예측 불가** | 사후 대응 | 72시간 전 예측 |

---

## 2. 솔루션 (Solution)

### 2.1 in·ev·it·able의 의미

```
in·ev·it·able /ɪˈnevɪtəb(ə)l/

1. 피할 수 없는, 필연적인
2. 반드시 일어나는

"데이터가 흐르면, 증빙은 필연적으로 따라온다."
```

**Qetta가 만드는 필연:**
- 데이터 수집 → **필연적** 품질 향상
- AI 분석 → **필연적** 비용 절감
- 자동 증빙 → **필연적** 지원금 수령

### 2.2 핵심 파이프라인

```
┌─────────────────────────────────────────────────────────────────┐
│                    Data Flows. Evidence Follows.                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│   [OTT칩]  →  [AI 예지보전]  →  [Evidence Registry]  →  [Gov ZIP] │
│      │            │                   │                    │     │
│   10분 설치    72h 예측          변조 탐지 가능         정부 제출    │
│   50만원      고장/불량         SHA-256 해시          자동 생성    │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 2.3 제품 구성

#### OTT칩 (One-Touch Telemetry)

```
┌──────────────────────────────────────┐
│           OTT칩 v2.0                  │
├──────────────────────────────────────┤
│  • 비침습 설치 (기존 설비 무관)        │
│  • 10분 설치 완료                     │
│  • 50만원 (MES 대비 99% 절감)         │
│  • 실시간 데이터 수집                 │
│  • 5G/WiFi/LoRa 지원                 │
└──────────────────────────────────────┘
```

#### AI 예지보전 엔진

| Tier | 비중 | 방식 | 비용 |
|------|------|------|------|
| 1 | 95% | Rule-based | 0원 |
| 2 | 4% | ML (pgvector) | 50만원/년 |
| 3 | 1% | Claude API | 600만원/년 |

**성과:**
- 불량률 -30%
- 설비 정지 -80%
- ROI 회수 기간: 0.7개월

#### Gov ZIP (증빙 패키지)

```json
{
  "manifest_version": "1.2",
  "generator": "Qetta v1.0.0",
  "package_hash": "sha256:...",
  "retention_hint": {
    "min_days": 1825,
    "regulation": "스마트공장 보급사업 관리지침",
    "note": "정부사업 증빙 자료 - 5년 보관 권장"
  }
}
```

**특징:**
- 변조 탐지 가능 (tamper-evident)
- SHA-256 해시 무결성 검증
- 정부 제출 양식 자동 준수
